Loose /ends

Where "Start a service" doesn't match this flow yet · found Oct 31, 2026

  • BRAVO, Website-only and App-only create no care-plan tasks

    Start a service for these packages has no HyperCare+ or GravïtyCare stream, so the required care plan has to be started as a second service.

  • ALPHA always adds GravïtyCare

    Mission ALPHA includes the GravïtyCare SOP automatically. If the client picks HyperCare+ (which already includes GravïtyCare), starting HyperCare+ adds the GravïtyCare steps a second time.

  • Command System SOP has no care-plan hand-off step

    The website SOP ends with "GravïtyCare or HyperCare+ tier active". The system SOP ends at the 30-day support window.

  • No price on Website-only, App-only or Transmission

    These start with a $0 contract value, so projects and revenue show nothing until the price is typed in.

  • HyperCare+ Local price differs

    Start a service offers $500–$750/mo; the deliverables and website say $750/mo.

  • Closing the sale has no SOP

    Stage 01 is shown from the order the system expects. Turning it into an SOP would put it in the task list too.
